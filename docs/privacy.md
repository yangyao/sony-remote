# 隱私與本機資料

App 直接與使用者設定的區網電視通訊，沒有廣告、分析 SDK、使用者帳號或雲端服務。

- 電視 IP 與穩定的配對 client ID 儲存在裝置 UserDefaults。
- PIN 僅用於當次配對，不寫入持久儲存。
- 電視回傳的配對 cookie 依地址保存在本機 Keychain，不放入原始碼。
- PSK 模式的金鑰目前仍儲存在裝置 UserDefaults，不會隨程式庫提交。
- 已安裝版本升級時保留本機地址和配對；全新安裝須自行填寫 IP。
- 公開演示使用文件專用的 `192.0.2.x` 地址及虛構認證資料。IRCC 的 Base64 字串是 Sony 按鍵協定常數，不是密鑰。

演示截圖已移除附加的個人影像中繼資料。公開來源保留必要的上游授權與來源標示。
