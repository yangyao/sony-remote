# Apple TV Remote — Liquid Glass 材質參考

2026-10-30 依使用者請求，從其已開啟 Apple TV Remote 的 iPhone 15 擷取 `iphone-reference.png`（1179 × 2556 px，3x）。

使用者明確要求保留 Sony Remote 原有的圓形方向盤、按鍵位置與直向音量膠囊，因此只參考純黑／中性灰配色、按鍵邊緣高光與玻璃材質，不採用大圓角觸控板。

原生實作依據：[Apple SwiftUI Liquid Glass 文件](https://developer.apple.com/documentation/swiftui/applying-liquid-glass-to-custom-views)。
