# 介面

- 主畫面僅有電視名稱、電源、圓形方向盤、返回、首頁、播放／暫停、靜音及直向音量加減。
- 沒有底部分頁、額外標題、正在播放內容或獨立的狀態文字。電源顏色表達開機／待機／未連接。
- 方向與音量可按住連發，方向盤支援滑動；保留基本控制和無障礙標籤。
- 兩端自動跟隨系統深淺色，玻璃材質以系統 API 呈現；降低透明度時使用不透明表面。
- Connection 直接使用英文，只保留 TV IP、Connect 與收合的 Advanced。首次安裝不填入私人 IP。
- 需要授權時提供 PIN、Pair TV、Show code again；成功後回到遙控器，不保留 PIN。
- Mac 控制中心只提供一個入口，開啟包含所有基本控制的 App 窗口。
