# iPhone 遙控器 UX

依使用者確認：保留圓形方向盤、既有按鍵位置與直向音量膠囊；只更新黑灰配色與原生 Liquid Glass 材質。不改成 Apple TV 的大觸控板，不顯示「正在播放」內容。

## 已實作

- 頂部只顯示電視名稱與電源；點電視名稱開啟精簡設定面板。預設 IP 為 192.0.2.1，設定只顯示 IP 與「連接」，PSK 收進進階設定；移除教學與獨立測試入口。
- 中央圓形導航區，點中央確認，點／按住四方向圓點或滑動導航。
- 下方兩欄：左側返回、播放控制、靜音；右側首頁、直向音量加減。
- 音量是 Sony 電視音量，不使用 iPhone 系統音量；按住會連發。
- 播放入口提供明確的播放／暫停選單，避免假設電視提供切換指令或可靠播放狀態。
- 移除底部 App、輸入源、更多控制與其面板；手機端只做基本遙控。
- 所有主按鍵提供無障礙標籤；按住連發在放手、離開畫面或 App 進入背景時停止。
- 沒有 SONY REMOTE 重複標題、待機狀態文字、播放資訊卡片、廣告或底部分頁。電源鍵以綠／橙／灰表示開機／待機／未連線，連線中顯示轉圈；VoiceOver 仍可讀取完整狀態。
- 不實作手機文字輸入與自動鍵盤；低頻輸入使用電視螢幕鍵盤或實體遙控器。

## 限制

Sony IRCC 是離散按鍵，滑動會映射成方向指令；不是 Apple TV 的連續觸控協定。待機喚醒、認證方式與可用按鍵須以實體電視驗證。預設使用個人電視 IP，沒有自動搜尋；需要認證時自動進入 PIN 配對。

## Mac 後續

共用操作語意與通訊核心，增加選單列、浮動面板及鍵盤捷徑。Mac 版尚未實作。

## Liquid Glass 更新

- 純黑背景、中性灰方向盤，移除紫色。
- 確認、電源、返回、首頁、播放、靜音與音量膠囊使用 iOS 26+ `glassEffect(.regular.interactive())`；同組功能鍵置於 GlassEffectContainer。
- 方向盤外圈保留低調的實色表面，避免在確認鍵下再疊一層玻璃。幾何尺寸、點按／按住／滑動語意不變。
- 按壓時不再將按鍵大幅淡出，以保留系統玻璃高光。降低透明度時使用不透明表面；舊系統使用 ultraThinMaterial。
- [使用者手機上的 Apple TV 材質參考](references/apple-tv-liquid-glass/README.md)只用於材質與配色，不複製其布局。

## 設定語言

IP 設定頁直接使用英文：Connection、Done、TV IP、Connect／Connecting…、Advanced、Pre-shared key (PSK)。連線錯誤提示與頁內無障礙標籤也使用英文，不新增翻譯檔或語言切換。主遙控器的語言與布局不變。

## 一次性配對

控制被拒絕或啟動時未取得授權，直接開啟 Connection。電視未開機時只提示先開機；開機後顯示 PIN 欄位、Pair TV 與 Show code again。配對成功儲存 cookie 到 Keychain，清除 PIN 並返回原遙控器。平常的設定仍只顯示 IP、Connect 與收合的 Advanced。只讀電源狀態不等於有控制權。


## 系統外觀與圖標

iPhone 與 Mac 移除固定深色設定，自動跟隨系統外觀。原布局與按鍵尺寸不變：淺色使用近白底、淺灰方向盤及深色圖形，深色使用黑底、深灰方向盤及淺色圖形；維持原生玻璃材質。設定頁、分隔線、降低透明度的表面也使用自適應色彩。沒有新增主題設定。

兩端使用同一個原創遙控器圖形作為 AppIcon，並按平台輸出尺寸與外觀資源。iPhone 有普通／深色／染色版本；Mac 由資源目錄產生圖標。
