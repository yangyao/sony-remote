# iPhone 遙控器 UX

依使用者確認：以 Apple TV Remote 為操作方向，參考 DM TV Remote 的直向音量膠囊與簡潔深色布局，不顯示「正在播放」內容。

## 已實作

- 頂部電視名稱、連線狀態、電源；點電視名稱開啟精簡設定面板。預設 IP 為 192.0.2.1，設定只顯示 IP 與「連接」，PSK 收進進階設定；移除教學與獨立測試入口。
- 中央圓形導航區，點中央確認，點／按住四方向圓點或滑動導航。
- 下方兩欄：左側返回、播放控制、靜音；右側首頁、直向音量加減。
- 音量是 Sony 電視音量，不使用 iPhone 系統音量；按住會連發。
- 播放入口提供明確的播放／暫停選單，避免假設電視提供切換指令或可靠播放狀態。
- 底部 App、輸入源、更多控制；更多包含數字鍵、頻道、字幕等。
- 所有主按鍵提供無障礙標籤；按住連發在放手、離開畫面或 App 進入背景時停止。
- 沒有播放資訊卡片、廣告或底部分頁。

## 限制

Sony IRCC 是離散按鍵，滑動會映射成方向指令；不是 Apple TV 的連續觸控協定。待機喚醒、認證方式與可用按鍵須以實體電視驗證。第一版手動填寫 IP，沒有自動搜尋或 PIN 配對。
